## About

This is a web-based catering planning application built as a personal student project (course [**PROJ0011
**](https://www.programmes.uliege.be/cocoon/20262027/en/cours/PROJ0011-1.html), University of Liège) under the
supervision of Prof. Bernard Boigelot.
The project is developed in collaboration with a real-world sponsor, [Foodink](http://foodink.be/), a catering company
based in East Belgium.

The application aims to replace manual, paper-based catering menu management with a digital platform offering:

- A QR-code based digital event menu
- Allergen and dietary filtering for guests
- An admin panel for restaurant/catering staff
- Multi-tenant architecture, isolating data between different catering businesses

## Contributing

Because this project is being individually graded as academic work:

- 🚫 **No pull requests will be accepted** until after the final evaluation (June 2027).
  Any code submitted before then cannot count toward my grade, so PRs will stay open without merging, no matter how good
  they are.
- 💡 **Feature ideas and suggestions are very welcome** — feel free to open an issue or start a discussion!
  However, please note that the project scope is defined by a [specification](SPECIFICATION.md) approved by my
  university coordinator and
  sponsor.
  Suggested features may be noted as potential future work but are **unlikely to be implemented before the evaluation
  deadline**, since the specified scope takes priority.
- 🐛 Bug reports on published code are welcome at any time.

After the evaluation is complete, this policy will be revisited and the project may open up to community contributions.
